# Történeti fejlesztési dokumentumok

Ez a könyvtár korábbi review-, audit- és implementáció előtti dokumentumokat őriz. Ezek **nem normatív specifikációk**; a jelenlegi viselkedést a `docs/`, `svm_asm/docs/`, `svm_rt/docs/` és `svm_c/docs/` aktív referenciái írják le.

A történeti fájlok elsősorban a tervezési döntések fejlődésének visszakövetésére szolgálnak. Aktuális implementációs kérdésben mindig a normatív dokumentációt és a forráskódot kell elsődlegesnek tekinteni.
